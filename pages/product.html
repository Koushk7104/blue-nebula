Before you step inside.

The prototype is available to explore without connecting your repository or an AI service.

Is there a desktop app I can install today?

This deliverable is the website and browser-local prototype. The desktop application, local model runtime, repository integration, and installer remain work described in the product proposal.

Will editing the prototype upload my project?

The prototype edits an authored sample configuration in your browser. It does not connect to a repository. Project import reads the selected JSON locally; exports are generated on your device.

Does the guided task call an AI model?

No. It routes supported welcome, dashboard, and settings requests through a scripted demonstration. Manual inspection pauses automatic view changes.

What do the checks prove?

The five fixture checks inspect heading content, layout bounds, registered tokens, the action label, and safe text serialization. They do not compile a project, test a running application, or qualify the desktop product.

Can I keep the work I do in the demo?

Configuration and checkpoints persist in this browser when storage is available. Export a project JSON file to keep them together, then import it later. You can also download generated source, tokens, a patch, and evidence reports.
